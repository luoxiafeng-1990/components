Worker Architecture Overview

This animation shows the detailed architecture of FFmpegDecodeWorker, highlighting the DataSource (packet_source_) and its peer components within the WorkerBase class and WorkerConfig.

The Worker is built on a layered architecture: WorkerBase provides common functionality, WorkerConfig contains all configuration parameters, and runtime components handle data flow from source to output buffers.
