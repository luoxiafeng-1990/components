DataSource 三种模式
FFmpegDecodeWorker 构造函数中根据配置创建不同 packet_source_
📁
文件模式
EncodedPacketSourceFromFile
从本地视频文件逐包读取编码数据。buffer_count=128，适用于离线测试。
packet_source_ = make_shared<FromFile>(path, max_frames);
📁本地 .mp4 / .h264 文件
→avformat_open → av_read_frame 逐包
→acquireEncodedPacket() → AVPacket
📡
RTSP 网络流
EncodedPacketSourceFromRtsp
从 RTSP 摄像头实时接收编码包。buffer_count=8 低延迟。
if (path.rfind("rtsp://",0)==0) packet_source_ = make_shared<FromRtsp>(path);
📹摄像头 RTSP 服务器
→RTP 实时推送编码帧
→acquireEncodedPacket() → 实时 AVPacket
🔄
共享缓冲区
EncodedPacketSourceFromBuffer
从上游 RecordWorker 的 BufferPool 零拷贝获取编码包。MultiWorker 级联场景。
packet_source_ = config.data_source.shared_packet_source; // 或 make_shared<FromBuffer>(codec_params);
🔄上游 Worker BufferPool
→zero-copy 读取 AVPacket
→acquireEncodedPacket() → 共享帧
